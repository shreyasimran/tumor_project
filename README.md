# Brain Tumor Detection (Brain Tumor vs Healthy)

## Project Overview
This project detects the presence of a brain tumor from MRI images using a deep learning approach. The system performs binary classification to predict whether a given brain MRI image belongs to the Brain Tumor or Healthy category.

## Problem Statement
Manual analysis of brain MRI images is time-consuming and depends on expert knowledge. This project aims to assist in early detection of brain tumors by automating the classification process using deep learning techniques.

## Dataset
- Brain MRI image dataset
- Two classes:
  - Brain Tumor
  - Healthy

## Model Used
- CNN-LSTM architecture
- Convolutional Neural Network (CNN) for feature extraction
- Long Short-Term Memory (LSTM) for learning sequential image features
- Implemented using Python

## Features
- Binary classification (Brain Tumor / Healthy)
- Works on brain MRI images
- Simple and efficient detection system
- Suitable for academic and learning purposes
