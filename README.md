# Brain Tumor Detection using CNN-LSTM

## Project Overview
This project focuses on detecting brain tumors from MRI images using a CNN-LSTM deep learning model. The system classifies MRI scans into four categories: Glioma, Meningioma, Pituitary Tumor, and No Tumor.

## Dataset
- Source: Brain MRI Dataset (Kaggle)
- Classes:
  - Glioma
  - Meningioma
  - Pituitary
  - No Tumor

## Model Architecture
- Convolutional Neural Network (CNN) for feature extraction
- Long Short-Term Memory (LSTM) for sequence learning
- Framework: Python (TensorFlow / PyTorch)

## Features
- Accurate tumor classification
- Supports four tumor classes
- User interface using Gradio
